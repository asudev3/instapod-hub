# InstaPod Hub

Create a modern, responsive React + TypeScript dashboard for InstaPod with 3 role-based portals:

1. CUSTOMER

- Home dashboard

- Find InstaPod using GPS/map

- Nearby InstaPods

- InstaPod details & availability

- Service/order history

- Payments

- Notifications

- Profile

2. FRANCHISEE / DEALER

- Dashboard with InstaPod count, earnings and active campaigns

- My InstaPods & live status

- Advertisement revenue

- Revenue breakdown & franchisee payout

- Wallet & transaction history

- Troubleshooting alerts

- Support tickets

- Reports

- Notifications

3. ADVERTISER

- Dashboard with campaigns, spending, wallet balance and impressions

- Campaign management

- Create/Edit campaign

- Upload/change advertisement

- Select InstaPods

- Set duration & ad frequency

- Campaign analytics

- Renew campaign

- Wallet reload

- Payment history

- Notifications

DESIGN:

- Clean professional SaaS UI

- Sidebar + top navigation

- Responsive desktop/tablet/mobile

- KPI cards, tables, charts, filters and status badges

- Use Tailwind CSS + Lucide icons + Recharts

- Use realistic mock data

- Create reusable React components

- Role-based routing

- Include loading, empty, error and success states

Focus on making the dashboards production-quality and easy to connect to a backend/API later.
